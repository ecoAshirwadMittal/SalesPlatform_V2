### Confirmed-OK summary

- Page background `#F7F7F7` matches the QA convention (the project uses `#F7F7F7` for the dashboard page; Figma's exact `#F0EBE3` cream tone is a request-detail-page-level token per §6.1 but project-wide convention has stayed on `#F7F7F7`).
- Header field label / value typography colour tokens (`#6F6F6F` label, `#1C1B1C` value) match Figma §3.2 (`fill_T5QEJW` / `fill_4XBBOL`).
- Header field label font-size `13px` matches Figma `style_4XMI23` exactly.
- Header field value font-size `18px` matches Figma `style_OM5UY1` exactly.
- Status pill chrome (radius `999px`, white text, 12px font) matches the generic status-pill pattern.
- Reason-card box shadow `0 1px 2px -1px rgba(0,0,0,0.1), 0 1px 3px 0 rgba(0,0,0,0.1)` exactly matches Figma §3.5 callout.
- Sticky-column tint `#D8E5D9` matches Figma `fill_N47Q64` (§6.1) and is applied to both `<th>` and `<td>` for Action + Amount-to-Credit (later cascade rule wins over `.lineTable th` background — verified).
- Cell border `0.81px solid #A8A7A6` matches Figma table border spec (§2.4 / §3.5.2 — `fill_K51TIL`).
- Complete Review button green `#14AC36` matches Figma `fill_HX3N5P` (§3.4).
- Approve All button green `#14AC36` matches Figma (§4.1).
- Decline All button red `#B3261E` matches Figma + V89 seed (§4.1 / §6.1).
- Encumbered table column count = 9 (Barcode, Brand/Model, Grade, Box, Paid, Prolog Result, Actual Value, Action, Credit) — matches the §8.5 resolution to always render the `Actual Value` column.
- `Actual Value` placeholder text "Enter value" matches plan §11.Q3.
- Default outcome logic (Approved if ≥1 ACCEPTED, else Declined) — §11.Q4 — correctly implemented in `defaultOutcome` memo.
- Internal-status-text design intent for the header (§11.Q2) — implemented in the right place; only flag is that `displayStatus` is semantically ambiguous (see HIGH finding above).
- Per-line dropdown verbs `Accept` / `Decline` (singular) vs section bulk `Approve All` / `Decline All` (plural) — verb split correctly respected per §4.3.
- Section card border-radius `8px` matches Figma §3.5.
- Modal scrim `rgba(28, 27, 28, 0.5)` and centered modal pattern align with the rest of the app.
- `Confirm` / `Cancel` button copy in the modal matches §5.2 resolution.
- Encumbered Prolog Result label = `Prolog Result` (matches §8.4 resolution of `Prolog Result` over `Prolog Check`).
- `formatReasons` joins reasons with `, ` — matches Figma multi-reason display (line 1732 comma-joined sample).
